2. Why Linear Models Outperformed Neural Networks

  1. High-Dimensional Linear Separability: A 20,000-dimensional TF-IDF unigram+bigram feature space provides linearly separable boundaries for thematic news corpora. Linear SVM identifies the maximum-margin hyperplane without temporal decay.
  2. The Vanishing Gradient Problem in Simple RNN: Over sequences of length 150, multiplicative gradient backpropagation causes gradients to exponentially shrink to zero, leading to severe recency bias (37.16% accuracy).
  3. LSTM Constant Error Carousel (CEC): LSTM's additive cell state updates (C_t = f_t * C_{t-1} + i_t * C_tilde) preserved long-distance gradients, boosting Macro Precision to 70.82% with 100% precision on Business and 98% on Sports.

4. Calibrated Uncertainty Rejection Mechanism

Softmax probabilities are frequently overconfident on out-of-domain text. Linear SVM was calibrated using Platt Scaling (CalibratedClassifierCV), establishing an empirical threshold (T = 0.50):

if max_probability < 0.50:
    return "Unable to confidently classify this article."

Impact on 1,811 Test Articles: Baseline accuracy increased from 83.77% to 87.56% across 91.44% of accepted predictions, routing 155 ambiguous articles to editorial review.
